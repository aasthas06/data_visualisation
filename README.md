# Australian Wildlife Crisis: An Interactive Data Storytelling Visualisation

## Overview

Australian Wildlife Crisis is an interactive data visualisation project that explores the factors contributing to the decline of Australia's threatened wildlife. Built using Vega-Lite and deployed through GitHub Pages, the project transforms complex environmental datasets into interactive visual stories that help users understand biodiversity loss, conservation challenges, and extinction risks across Australia.

The visualisation combines multiple government datasets to present insights into threatened species, extinction drivers, habitat distribution, and geographical trends, allowing users to explore the data through interactive maps and charts.

---

## Project Objectives

* Visualise biodiversity and threatened species data across Australia.
* Identify the major drivers of species decline using interactive visualisations.
* Compare conservation trends across states and territories.
* Demonstrate effective data storytelling through coordinated interactive charts.
* Make complex environmental data accessible to a general audience.

---

## Key Insights

* Invasive species account for approximately **42.2%** of recorded extinction drivers, making them the largest contributor to biodiversity loss.
* Climate change contributes approximately **8.8%** of extinction drivers, highlighting that multiple threats impact Australian ecosystems.
* Threatened species are unevenly distributed across Australia, with several biodiversity hotspots requiring greater conservation attention.
* Geographic and demographic context provides additional insight into environmental pressures affecting wildlife habitats.
